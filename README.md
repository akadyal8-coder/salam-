# موقع حكم تشريح جثث الموتى

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد كما هي إلى مستودع جديد: `index.html` و`videos/` و`.nojekyll`.
2. من Settings ثم Pages اختر Branch: main ثم Folder: / (root) ثم Save.
3. يظهر الموقع بعد دقائق على الرابط الذي يعرضه GitHub.

## تعديل بيانات الطالب أو إضافة مقاطع
كل شيء داخل `index.html` في وسم script:
- `STUDENT`: الاسم والرقم الجامعي والشعبة الافتراضية (أو اكتبهما في الخانات أعلى الصفحة).
- `FATWAS`: أضف عنصرًا جديدًا. للفيديو ضع الملف في `videos/` واكتب `media:{url:"videos/اسم-الملف.mp4"}`.
